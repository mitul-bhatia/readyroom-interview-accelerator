# Readyroom reference capture

[Watch the internal reference capture](./readyroom-live-demo.mp4) (MP4, 2:15).

This is an internal rehearsal, not the applicant's final submission. It uses fictional candidate documents. Document analysis, questions, speech transcription, answer feedback, and the report all ran through the live Groq integration. A synthesized voice provided the sample microphone answer; narration was added after the screen recording. Brief scripted answers intentionally produce a low readiness score and a concrete preparation plan. The applicant will record their own demo using [the full script](../RECORDING_SCRIPT.md).
